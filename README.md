**Neon Coast Cover Studio** turns your photos into a neon-sunset poster cover in the style of GTA 6's multi-panel posters — right in the browser, fully offline, no upload, no watermark.

Add up to 6 photos, place each one in a panel, pick one of 6 layouts (Tilted Snapshots, Hero + Three, Four Grid, Nine Grid, Triptych, Full Bleed), grade it with one of 5 sunset/neon gradient maps, set the title in bold Anton lettering with a glowing Pacifico subtitle, add a star badge and a corner ribbon — then export a PNG in the post size you need: 1080 × 1080, 1080 × 1350, or 1920 × 1080.

Drag a photo to pan it, scroll over a panel to zoom, use the slider for fine control, and undo/redo anything. Your photos never leave your machine. Everything in the app is original: the fonts (Anton and Pacifico, SIL Open Font License) ship as files under `app/fonts/` — no Rockstar logos, artwork, wordmarks, or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Add photos, or try the included samples. No build step, no network requests: every script, font, and image the app loads is a file under `app/`.
